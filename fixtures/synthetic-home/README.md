# Synthetic home v1

Generated by `python -m twinforge.cli fixtures`. Geometry, replay timestamps, calibration points, and the PNG floor-plan drawing are authored synthetic examples. No real address, camera footage, biometric data, or participant is represented.

- `layout.json`: three rooms, hallway, exterior approach, entry zone, four portals, two cameras.
- `observations.json`: 12 replay records, including two explicit unknown gaps. Site/revision IDs are placeholders replaced by the API fixture route.
- `calibration.json`: six fit and four separate holdout points for the synthetic hallway mapping.
- `floorplan.png`: 960×720 drawing, nominal extent 12×9 m, for testing private image import. Geometry still requires two operator-entered scale checks after import.
